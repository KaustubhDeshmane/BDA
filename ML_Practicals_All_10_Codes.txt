MACHINE LEARNING PRACTICALS – ALL 10 PYTHON PROGRAMS
====================================================

Install required libraries:
    pip install numpy pandas scikit-learn

NOTE:
- These are small demonstration datasets for practical/viva practice.
- X contains input features; y contains target/output values.
- fit() trains the model; predict() predicts for new input.
- For multi-feature prediction, pass input as a 2D list: [[value1, value2, ...]].


1. SIMPLE LINEAR REGRESSION – EMPLOYEE SALARY
---------------------------------------------
Aim: Predict salary based on years of experience.

from sklearn.linear_model import LinearRegression

X = [[1], [2], [3], [4], [5]]
y = [20000, 30000, 40000, 50000, 60000]

model = LinearRegression()
model.fit(X, y)

exp = float(input("Enter years of experience: "))
salary = model.predict([[exp]])

print("Predicted Salary:", salary[0])

Sample input:
6

Expected output:
Predicted Salary: 70000.0

5. GRADIENT BOOSTING – EMAIL SPAM CLASSIFICATION
------------------------------------------------
Aim: Classify an email as Spam or Not Spam.

Features: Number of suspicious words, number of links.
0 = Not Spam, 1 = Spam

from sklearn.ensemble import GradientBoostingClassifier

X = [
    [1, 0], [2, 1], [1, 1], [2, 0],
    [8, 5], [9, 6], [7, 4], [10, 8]
]
y = [0, 0, 0, 0, 1, 1, 1, 1]

model = GradientBoostingClassifier(random_state=42)
model.fit(X, y)

words = int(input("Enter suspicious words count: "))
links = int(input("Enter number of links: "))
result = model.predict([[words, links]])

if result[0] == 1:
    print("Email is Spam")
else:
    print("Email is Not Spam")

Sample input:
9
6

Expected output:
Email is Spam

9. SVM – TISSUE CLASSIFICATION
------------------------------
Aim: Classify a tissue sample as Benign or Malignant.

Features: Cell size, cell texture.
0 = Benign, 1 = Malignant.

from sklearn.svm import SVC
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import make_pipeline

X = [
    [1, 2], [2, 1], [2, 3], [3, 2],
    [7, 8], [8, 7], [9, 8], [8, 9]
]
y = [0, 0, 0, 0, 1, 1, 1, 1]

model = make_pipeline(StandardScaler(), SVC(kernel='linear'))
model.fit(X, y)

size = float(input("Enter cell size: "))
texture = float(input("Enter cell texture: "))
result = model.predict([[size, texture]])

if result[0] == 0:
    print("Tissue is Benign")
else:
    print("Tissue is Malignant")

Sample input:
8
8

Expected output:
Tissue is Malignant


10. SVM – ADVERTISEMENT CLICK PREDICTION
----------------------------------------
Aim: Predict whether a user will click an advertisement.

Features: Time spent on website, previous ad clicks.
0 = No Click, 1 = Click.

from sklearn.svm import SVC
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import make_pipeline

X = [
    [1, 0], [2, 0], [3, 1], [2, 1],
    [7, 4], [8, 5], [9, 5], [10, 6]
]
y = [0, 0, 0, 0, 1, 1, 1, 1]

model = make_pipeline(StandardScaler(), SVC(kernel='linear'))
model.fit(X, y)

time = float(input("Enter time spent on website: "))
clicks = int(input("Enter previous ad clicks: "))
result = model.predict([[time, clicks]])

if result[0] == 1:
    print("User will Click the Ad")
else:
    print("User will Not Click the Ad")

Sample input:
8
5

Expected output:
User will Click the Ad

IMPORTANT SKLEARN FUNCTIONS
===========================
model = Algorithm()
model.fit(X, y)             # Train the model
model.predict([[input]])   # Predict output for new input

X = input features (independent variables)
y = target/output (dependent variable)

Regression     -> predicts a numerical value
Classification -> predicts a category/class
